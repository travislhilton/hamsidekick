Set Up Your VARA Modems

New here? Get the station

Keyboard chat and file transfer over VARA HF or VARA FM. Each data radio has one VARA modem (a copy of VARA with its own sound card and ports), and each modem is used for one job. Several can be on the air at once. Everything is sent in the clear; nothing transmits unless you are at this PC (sending, joining the channel, or its keep-alives).

What each modem is for (Modem setup → Used for)

Chat & filesThis station only. Winlink Express uses a different modem
Shared with Winlink ExpressThey take turns: while Express is open and you are not in a chat, Express has it; the station takes it back when Express closes
Winlink Express onlyThe station never connects to it (listed so you see the whole station)

Two ways to set it up

One radio, taking turnsOne VARA (ports 8300/8301, Express's default) → Shared
Separate radiosRadio A: VARA FM 8300/8301 → Winlink Express only. Radio B: a second VARA 8310/8311 → Chat & files. A third: 8320/8321

Set up each modem

1
The radio's card: Used for → Data (Winlink / VARA)Its nets are not recorded, and the station never records from the VARA sound card.
2
A second copy of VARA? Install or copy it into its own folder (e.g. C:\VARA FM 2); in it: VARA Setup → TCP port 8310 · Sound card = this radio's · PTT = this radio'sVARA HF and VARA FM are licensed separately: check VARA's terms for a second copy.
3
Under the radio: Set up the VARA modem… → VARA HF or FM · Ports (the next free pair is filled in) · Used for → Add this modem · then Call with an SSID to tell your stations apart (W9XYZ-7, W9XYZ-8; apart from Winlink's)VARA FM: Width Narrow or Wide, the same as in VARA FM (wide = the 9600 data port, ~25 kHz; the band plan offers it only where there is room).
4
Before it can transmit: Radios… → the radio → Transmit on · your license class (Settings → Sidekick & AI) · the radio's frequency on its card
Ham practice. A COM port opens in one program only: if the station tunes this radio by CAT, give VARA another PTT (RTS on a separate port, the Digirig's second port, or VOX). Two 2 m radios side by side desense each other: use different bands (Winlink on 2 m, chat on 70 cm or HF) or well-spaced antennas. Each transmission IDs as usual.

Join the channel (under the data radio: VARA chat and files)

1
Pick a frequency: Band plan → Ad hoc VARA → Use (or a ★ reserved channel). Listen first
2
Join the channel: announces your call (a VARA CQ frame), answers calls, and says you are still here every 10 min (VARA HF 15; 5–60)Only while you are at this PC with the Transmit switch on: all of it pauses when you leave.
● hereAnnounced or linked within the keep-alive time (and 3 min grace)
○ quiet (grey)No keep-alive heard: may have left. Under Earlier after 3 intervals
🔗 linked · ⏳ · ⚠The station linked now · messages waiting to go · not sent (Retry)

Chat and files (VARA links one station at a time)

3
Click a station → type → Enter · 📎 a file (5 MB) · quick messages fill the box (Edit; {them} {sn} {me})Tick several, or Select everyone here: each gets the message over its own link, one after another.
4
It goes by itself: ⏳ waiting → a short link when the frequency is clear → ✓ sent → ✓✓ delivered; the link closes after 20 s of quietKeep the link open for a back-and-forth. 3 calls unanswered: ⚠ Retry. Leave · Abort (drops any link at once).
5
Files received are downloads, never opened; a .hsadhoc file: ★ Install · Modem setup… → Direct link: Connect / CQ / Answer calls by hand

Taking turns with Winlink Express (a Shared modem)

6
Automatic: open Winlink Express → the station lets go (after your chat, if one is under way) → close Express → it takes VARA backModem setup… → Hand to Winlink Express now / Take it back do the same by hand.
